# V1 transition audit — 2026-10-03

The merged frozen v2 implementation is the accepted baseline. Literal parity with every v1 feature is **not achieved**. The operator authorized an explicit decision queue first, then obsolete-v1 cleanup; opening these issues makes no implementation commitment. No active v1 application runtime was found, so this cleanup updates documentation only.

## Scope and method

Baseline: main `8e57a1012a1bdb0d270386b2c1037dd5f624c461`, 423 tracked files. All 50 existing issue records and 77 PR records were inventoried before creating the follow-on issues. A whole-tree static scan and targeted semantic review mapped frozen requirements and original v1 issues to current implementation and meaningful checked-in tests. This was not exhaustive manual line-by-line review, full historical behavior replay, or a proof of all-v1 parity. Closed issue state alone was not treated as implementation evidence. The committed `.env.example` template was inspected safely; ignored `.env` files and secret values were not read. No live Brewfather/Home Assistant calls or production mutation were performed.

The audit found stale schema-21 and pre-merge/follow-up claims, now reconciled in README, implemented architecture, guardrails, and STATUS. Earlier exact-revision acceptance remains historical. Frozen TARGET/FREEZE/DECISIONS, ADRs and the reuse manifest remain unchanged; discrepancies are recorded for explicit decisions rather than silently changing architecture.
